# PS3 XMB media

These files are copied to the root of the generated PS3 PKG beside `PARAM.SFO`.

- `ICON0.PNG`: PS3 static XMB icon (320x176).
- `LOGO0.PNG`: requested logo filename alias (320x176). The XMB reads `ICON0.PNG` as the static icon.
- `PIC1.PNG`: PS3 XMB background (1920x1080).
- `SND0.AT3`: XMB selection sound. The supplied source is copied without decoding, re-encoding, or modification.
